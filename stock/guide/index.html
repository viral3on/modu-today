증시 스캐너: 숫자가 만들어지는 과정

데이터가 어디서 오고 어떤 비교를 거쳐 화면의 신호가 되는지, 실제 프로그램에 적용한 기준을 숫자 예시로 설명합니다. 아래의 모든 종목·가격 예시는 계산법 설명을 위한 가상값입니다.

1. 수집 범위와 시간부터 확인

기본 데이터는 한국거래소(KRX) OPEN API의 유가증권·코스닥 일별매매정보입니다. 프로그램은 최근 최대 121거래일을 수집해 종목별 거래량, 거래대금, 종가, 고가 등을 비교합니다. 화면의 거래일과 갱신 시각은 서로 다른 개념입니다. 오늘 페이지를 열었더라도 데이터가 어제 거래분이면 어제 기준으로 읽어야 합니다.

지수·ETF·ETN·금시장 등의 추가 API는 별도 활용승인 또는 수집 상황에 따라 표시되지 않을 수 있습니다. 빈 영역이 해당 시장에서 거래가 없었다는 뜻은 아닙니다. 데이터가 오래되었거나 누락되었다면 증권사·거래소 원자료로 다시 확인하세요. KRX OPEN API 서비스 목록 ↗

2. 거래량·거래대금 급증의 계산법

거래량 배수는 오늘 거래량 ÷ 직전 최대 20거래일의 일평균 거래량입니다. 거래대금 배수도 동일한 방식으로 거래대금을 비교합니다. 평균을 낼 때는 유효한 양수 거래일만 사용하며, 비교할 데이터가 없다면 급증으로 판정하지 않습니다.

가상 예제
직전 20거래일 평균 거래량이 40만 주이고 오늘 120만 주라면 120만 ÷ 40만 = 3배입니다. 평균 거래대금이 100억 원이고 오늘 250억 원이라면 거래대금 배수는 2.5배입니다. 두 배수는 각각의 기준이 2배 이상이므로 ‘거래량 급증’과 ‘거래대금 급증’에 모두 해당합니다.

‘이상거래 포착’은 두 배수 모두 2배 이상이면서 당일 등락률의 절댓값이 2% 이상인 경우입니다. 거래량만 많거나 가격만 오른 종목은 이 조건에 들어가지 않습니다. ‘돈 몰린 종목’은 당일 거래대금 100억 원 이상이면서 거래대금 배수가 1.5배 이상일 때 표시합니다.

3. 신고가와 추세의 의미

항목실제 판정 방식읽을 때 주의할 점
20일 신고가오늘 종가가 직전 최대 20거래일의 일중 최고가 이상장중 고가만 넘고 종가가 밀렸다면 해당하지 않음
60일 / 120일 신고가같은 방식으로 직전 60일 / 120일의 고가와 비교비교 이력 최소 40일 / 80일이 필요함
5일 연속 상승최근 6개 종가 사이의 연속 5번 변화가 모두 상승같은 가격으로 마감한 날이 끼면 연속 상승으로 세지 않음
추세 강화최근 5거래일 수익률 5% 이상, 20거래일 수익률 10% 이상, 당일 등락률 양수과거 흐름의 분류이며 향후 수익률 예측이 아님
가상 예제
직전 20거래일 중 가장 높았던 장중 가격이 56,000원이고 오늘 종가가 57,000원이면 ‘20일 신고가’ 조건을 만족합니다. 오늘 장중 가격만 57,000원에 도달하고 종가가 55,000원이라면 만족하지 않습니다.

4. ‘MODU 관심도’는 무엇을 뜻하나요?

관심도는 거래량 비율(최대 18점), 거래대금 비율(18점), 절대 거래대금(18점), 당일 가격 변화(10점), 5일·20일 추세(합계 16점), 신고가(12점), 시가총액 구간(8점)을 합산하고 조건에 따른 감점을 적용한 자체 지표입니다. 점수는 0~100 범위로 제한됩니다. 이 지표는 시장 전체에서 종목을 정리하기 위한 도구일 뿐, 투자 가치나 상승 확률을 뜻하지 않습니다.

예를 들어 거래량 배수가 3배이면 거래량 기여점수는 min((3−1)×4.5, 18)=9점입니다. 단기간 급등, 매우 낮은 거래대금, 높은 회전율 등에는 별도의 감점이 있습니다. ‘주목 TOP’에는 관심도 55점 이상, 당일 거래대금 30억 원 이상, 거래 급증·신고가·상승 추세 중 하나 이상의 맥락을 충족한 종목만 들어갑니다. 55점은 매수 기준이 아니라 사이트 내부의 분류 기준입니다.

5. 결과를 비교하는 순서

  1. 화면 상단에서 실제 거래일을 먼저 확인합니다.
  2. 거래량 배수와 거래대금 배수가 함께 증가했는지 구분합니다.
  3. 신고가가 ‘오늘 종가’ 기준인지, 추세가 과거 수익률에 기반한 것인지 확인합니다.
  4. 공시, 거래정지 여부, 기업 이벤트, 시장 전체의 변동은 별도로 조사합니다.
  5. 수치가 중요한 의사결정에 쓰일 때는 KRX와 증권사의 원자료를 대조합니다.
정보 이용 시 유의사항
이 서비스는 실시간 주문·호가 시스템이 아닙니다. 과거 데이터에서 특이 움직임을 분류할 뿐 미래 가격, 손익 또는 특정 종목의 적합성을 보증하지 않습니다. 수집 오류, API 반영 지연, 종목별 거래 이력 부족으로 일부 결과가 빠질 수 있습니다.
