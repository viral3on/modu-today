관리자 인증

이 사이트의 GitHub 저장소 관리자만 사용할 수 있습니다.

처음 사용하는 경우

GitHub의 Settings → Developer settings → Personal access tokens → Fine-grained tokens에서 이 사이트 저장소만 선택하고 Contents에 Read and write 권한을 부여하세요. 짧은 만료 기간을 권장합니다.

토큰은 현재 탭의 메모리에만 보관하며, 사이트 서버를 거쳐 GitHub에 권한 확인과 발행 요청을 보낼 때 사용합니다. 새로고침하거나 연결을 종료하면 다시 인증해야 합니다. 공용 기기에서는 사용하지 마세요.

발행한 글과 수정 이력은 공개 저장소에 남습니다. 개인정보나 비밀정보를 본문에 넣지 마세요.
