# MODU.TODAY 콘텐츠 가치·외부 데이터 권한 점검 (2026-09-18)

이 문서는 운영 사이트의 소스와 공식 이용조건을 함께 검토한 기록이다. AdSense의 거절 문구는 ‘가치가 별로 없는 콘텐츠’이고, 구글이 개별 페이지·저작권·API 사용을 거절 원인으로 특정한 증거는 없다. **기술 점검과 외부 사용자 경험담으로 AdSense 승인을 예측하지 않는다.** 아래 항목은 법률 의견이나 라이선스 허가가 아니다.

## 실증적으로 확인한 위험

### 1. KRX OPEN API: 상업화·제3자 공개 권한 확인 필요 (최우선)

- 현재 `stock/update_stock.py`는 `KRX_API_KEY`로 KRX 공식 OPEN API (`data-dbg.krx.co.kr/svc/apis`)의 종목별 일별 매매정보를 수집한다. `/stock/`은 해당 데이터에서 만든 종목/지표를 방문자에게 표시하며, 정적 데이터 파일도 공개 경로에 생성한다.
- **KRX OPEN API 약관 제6조 제2항:** 비상업적 목적으로만 API 사용 가능, API 결과에 대한 대가 청구 불가. **제11조 제2항:** KRX로부터 제공받은 정보를 제3자에게 제공할 수 없음. 제10조 제3항은 활용한 화면에 ‘한국거래소 통계정보’ 사용 사실의 표시를 요구한다. 적용 약관 페이지의 시행일은 2025-12-26이다.
- 광고 수익이 발생하는 공개 증시 서비스가 위 조항 또는 별도 승인·라이선스의 예외에 해당하는지는 **해당 API 승인 범위/개별 계약을 KRX 측에 서면으로 확인**해야 한다. API 키가 정상 작동하거나 출처를 표시했다는 사실만으로 상업 이용·공개 재분배 허가가 입증되지 않는다. 저작권 침해 확정이 아니라 이용약관/재분배 권한 위험이다.
- 확인 전에는 제3자 제공·광고 수익을 허용한다고 단정하지 않고, 현재의 주식 데이터 제공을 계속할지/별도 허가를 받을지 운영자 결정이 필요하다. 자동으로 핵심 스캐너를 삭제하거나 비공개 처리하지 않았다.
- 공식: https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO002.jsp , https://openapi.krx.co.kr/contents/OPP/DATA/OPPDATA003.jsp

### 2. YouTube 조회수 증가 랭킹: API 파생 지표 및 저장 승인 확인 필요

- `youtube/update_youtube.py`는 공개 영상 API 조회수를 날짜별 JSON으로 저장하고, 일간/주간/월간 증가량을 계산한다. 사이트는 영상 제목·채널·API 제공 썸네일을 표시하고 원본 YouTube 영상으로 이동시킨다. 영상 자체를 내려받거나 사이트에 재업로드하는 코드는 해당 파일에서 발견되지 않았다.
- YouTube는 추가 파생 지표/저장 정책 수락·승인된 분석 용도에 따라 조회수 증가 순위 같은 리더보드를 허용한다. **이 프로젝트가 해당 개정 정책을 수락·승인받았는지는 연결된 GitHub 코드만으로 확인 불가.** 승인되지 않은 공개 API 데이터의 저장은 일반적으로 30일 한도 및 갱신/삭제 의무가 있으므로 날짜별 이력의 실제 보관기간도 점검해야 한다.
- 이 사항은 ‘저작권 위반 확정’이 아니라 API 개발자 정책 준수 여부에 관한 검증 항목이다. 프로젝트 승인 여부를 확인하기 전 영상 섹션이나 과거 데이터 파일을 일괄 삭제하지 않았다.
- 공식: https://developers.google.com/youtube/terms/developer-policies , https://developers.google.com/youtube/terms/derived-metrics-policy , https://developers.google.com/youtube/terms/developer-policies-guide

### 3. 뉴스 링크·로또 기록·공공 데이터: 저작권과 콘텐츠 가치 구분

- `update_news.py`는 Google News RSS의 기사 **제목과 출처를 링크**로 표시하며 기사 본문을 복제하는 로직은 확인되지 않았다. 기사 사진이나 전문 무단 전재를 확인한 것은 아니지만, 기사 제목만 나열하는 구성 자체는 독자적 편집/분석이 없으면 Google의 복제 콘텐츠·저가치 정책에 걸릴 소지가 있다. 링크·출처 표시만으로 원문 전재 권한이 생기는 것은 아니다.
- 로또 페이지는 공식 공개 추첨 결과의 수치·판매점 기록을 바탕으로 생성한다. 공개된 ‘숫자 사실’과 타사의 창작물 저작권 문제는 구분해야 한다. 실제 재사용 계약·원자료의 제공조건, 자동 호출 적합성은 미확인이다. 과도한 100회 템플릿 반복 여부는 콘텐츠 품질의 별도 문제이며, 권리 침해로 확인된 것은 아니다.
- 국토교통부 **아파트 매매 실거래가** 공공데이터포털 데이터셋은 공개 이용조건에 ‘이용허락범위 제한 없음’으로 기재돼 있다. 그러나 사이트의 특정 API·외부 리소스가 실제 동일 출처인지와 이용허가를 받았는지는 개별 코드/계정 기준으로 확인해야 한다.
- Google은 원본 출처의 복제·자동 생성 페이지를 독자적 부가가치 없이 광고 게재하는 것을 제한한다. 이는 별도 저작권 신고가 없어도 해당할 수 있으므로 저작권과 AdSense ‘가치가 별로 없는 콘텐츠’를 동일시하면 안 된다.
- 공식: https://support.google.com/publisherpolicies/answer/11190248?hl=ko , https://support.google.com/adsense/answer/7299563?hl=ko , https://www.data.go.kr/data/15126469/openapi.do

## 이번 점검에서 직접 반영하고 확인한 사실

- 로또 1241회 온라인 판매 5건이 지역 ‘서울’에 포함되어 실제 매장 8곳처럼 표시되는 오류를 찾아, **서울 오프라인 3건 + 온라인 5건**으로 분리했다. 판매점 고유 수가 아닌 ‘당첨 기록 건수’라는 단위로 전체 회차/100회 허브와 정기 갱신·SEO 재생성의 표시를 통일했다.
- 지역 분류/멱등성 테스트, 전체 SEO 재생성과 실제 배포 16개 URL 검증을 통과했다. 보고서: `docs/deployment-smoke.md`. 실제 AdSense 품질 판정은 아니다.

## 운영자 결정이 필요한 두 항목

1. **KRX**: 기존 계정에 상업 사이트 공개·제3자 제공을 명시적으로 허용한 별도 계약/허가가 있는지 확인한다. 없다면 권리를 명확히 할 때까지 스캐너의 KRX 데이터 공개를 중단하는 방식과, KRX에 별도 이용승인을 받는 방식을 비교해 결정해야 한다.
2. **YouTube**: 사용 중인 API 프로젝트의 추가 파생 지표 정책 수락/승인 여부를 확인한다. 미승인이라면 조회수 증가 순위의 임시 비공개 또는 승인 요청 등 운영자 판단이 필요하다.

Google AdSense의 3차 ‘검토 요청’은 아직 제출하지 않았다.
