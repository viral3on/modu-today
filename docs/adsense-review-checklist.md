# 애드센스 3차 신청 전 품질 점검

이 문서는 자체 점검표입니다. 구글의 개별 심사 결과를 예측하거나 승인을 보장하지 않습니다. 사이트 소유권 확인과 광고 승인 심사는 서로 별개입니다.

## 신청 전 필수 확인

- [ ] `/`, `/stock/`, `/calculator/`, `/lotto/`, `/youtube/`, `/apt/`, `/about/`, `/privacy/`, `/contact/`의 실제 운영 URL을 시크릿 창에서 PC와 모바일로 열고, 본문 및 기능 작동을 확인한다. 빈 데이터나 지속적인 로딩 문구를 정상 콘텐츠로 간주하지 않는다.
- [ ] `/ads.txt`가 실제 운영 도메인에서 HTTP 200으로 열리고 계정에 등록한 게시자 ID와 일치하는지 확인한다. ads.txt 상태만으로 저가치 콘텐츠 문제의 해소를 판단하지 않는다.
- [ ] 뉴스는 외부 링크 모음임을 표시하고, 자체 취재·사실 검증을 한 것처럼 표현하지 않는다. 제목만 나열하는 뉴스와 데이터 자동 출력에 의존하지 않고 원자료에 대한 독창적인 설명·해석 또는 실제로 유용한 도구를 제공한다.
- [ ] 각 도구의 계산식과 예제, 데이터 기준일, 출처, 한계가 실제 소스코드 및 제공 데이터와 일치하는지 검증한다. 임의의 최신 수치나 검증되지 않은 예측을 적지 않는다.
- [ ] 로또 회차 및 유사 템플릿 페이지를 개별 검토한다. 회차별 사실이 정확하며 목적이 분명한 기록 페이지만 유지한다. 반복 서술 추가만으로 고유 콘텐츠를 만들었다고 판단하지 않는다.
- [ ] 자동 배포 후 구버전 내용으로 되돌아가거나 정적 설명이 중복으로 추가되지 않는지 확인한다. GitHub Actions 실패 여부 및 실제 배포 상태를 확인한다.
- [ ] Google Search Console에서 주요 URL의 크롤링·색인 상태와 실제 렌더링을 확인한다. sitemap 등록은 색인 보장이 아니다.
- [ ] 제3자 콘텐츠 사용 권한과 출처를 확인하고, 데이터 수집 방식이 제공자의 이용조건에 부합하는지 검토한다.
- [ ] 수동 검토 결과를 확인한 뒤, 운영자가 애드센스에서 '문제를 수정했음을 확인합니다'와 '검토 요청'을 직접 수행한다.
