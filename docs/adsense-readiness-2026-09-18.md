# MODU.TODAY 애드센스 3차 신청 준비 점검 (2026-09-18)

이 문서는 실제 코드·배포 확인과 수동 확인이 필요한 사항을 구분한 작업 기록입니다. Google의 애드센스 검토 결과나 승인 가능성을 예측하지 않습니다.

## 확인된 수정과 검사

- 사이트 소유권은 애드센스 상세 화면에서 확인되었으나 콘텐츠 품질은 두 차례 거절되었음. 따라서 소유권·ads.txt만 해결하면 승인된다고 보지 않음.
- 뉴스 카드가 별도 CSS 없이도 읽히도록 수정하고, 외부 언론기사 링크임을 명확히 표시함. 자동 뉴스 생성 뒤 동일 수정이 유지되도록 후처리 추가.
- KRX 실제 데이터의 기준 거래일·종목 상승/하락/보합 분포·거래량 비교 예를 자체 계산해 홈페이지에 표시. 계산식/한계를 별도 스캐너 설명 페이지에 제공. 한국 시간대의 거래일 기준으로 검증함.
- 계산기 21종 허브에 수치 예제·기준값/상환방식 한계 설명 추가. 존재하지 않는 내부 메뉴 링크는 삭제하거나 실제 페이지로 교체함.
- 로또 100회 기록 허브에 원본 당첨번호로 계산한 과거 홀짝 분포·번호 합계 평균, 출처와 예측 불가 안내를 추가. 회차별 기록을 일괄 삭제하거나 검색 색인 제외 처리하지 않음.
- 사이트 소유권 인증용 HTML을 제외한 방문자용 HTML 141개를 정적 검사. 검사기 정의의 구조적 항목은 0건이며, 그중 102개 로또 회차 기록은 별도의 편집상 표본 검토가 필요함. 내부 숫자/문단 길이는 Google의 공식 승인 기준이 아님.
- 로또 최근 100개 회차의 저장된 추첨번호·보너스·날짜·제목과 생성 HTML, 최신 1등 당첨금 데이터를 자동 대조: 불일치·누락 0건. **공식 외부 원자료 진위 또는 전체 판매점 내용의 검증을 의미하지 않음.**
- 실제 운영 도메인의 홈페이지·ads.txt·스캐너·방법론·계산기·로또 기록·YouTube·아파트·게임·소개·문의·개인정보처리방침·이용안내·sitemap 등 14개 URL의 HTTP 200과 주요 문구를 확인함.
- 실제 Chromium에서 데스크톱/모바일 총 12개 시나리오를 실행: 모두 통과. 홈페이지 뉴스 카드 색상, 퍼센트 계산 2건, 증시 종목의 동적 표시, 나머지 주요 페이지의 본문/제목 렌더링을 확인함.

## 운영자 또는 연결 계정으로만 확인할 항목

1. Google Search Console의 주요 URL 검사에서 Google이 최근 수정 후 본문을 실제로 가져오고 렌더링하는지, 색인·차단 상태는 어떤지 확인. GitHub 코드와 사이트맵만으로는 알 수 없음.
2. 자동 생성된 로또 회차의 몇 개를 원자료 및 실제 방문자 관점에서 표본 검토. 외부 뉴스·영상·공공 데이터 사용 권한, 오래된 게시물의 정확성도 확인. 전체 사이트 정책 준수 여부는 정적 검사로 판단할 수 없음.
3. 애드센스의 정책 위반 세부 화면과 ads.txt 상태를 다시 확인한 뒤 운영자가 검토를 요청. 애드센스 내부 상태는 GitHub에서 확인하거나 대리 변경할 수 없음.

위 항목은 '검증 전'이지 '실패'를 뜻하지 않습니다. 검색 색인 상태와 Google 내부 심사를 확인하기 전에는 '승인 보장' 또는 '정책 위반 완전 해소'라고 말하지 않습니다. 신청 버튼은 사이트 운영자가 최종 점검 뒤 직접 눌러야 합니다.
