# MODU.TODAY 애드센스 3차 신청 준비 점검 (2026-09-18)

이 문서는 실제 코드·배포 확인과 운영자의 결정/수동 확인 항목을 구분합니다. Google의 애드센스 검토 결과나 승인 가능성을 예측하지 않습니다.

## 확인된 수정과 검사

- 애드센스 사이트 소유권은 앞서 운영자가 상세 화면에서 확인했으나 콘텐츠 품질 관련 거절이 두 차례 있었음. 소유권·ads.txt만으로 승인된다고 판단하지 않음.
- 홈페이지 뉴스 카드의 가독성을 복원하고 외부 언론 기사 링크임을 명시. KRX 일별 데이터의 기준 거래일과 직접 계산한 수치·해석 한계를 표시. 제목과 검색 설명도 사이트의 실제 서비스를 반영하도록 수정. 뉴스 및 SEO 자동 갱신 뒤에도 재생성되도록 연결.
- 계산기 21종 허브에 수치 예제와 조건·한계를 안내하고 잘못된 내부 링크를 정리.
- 로또 100회 기록 허브에 실제 저장된 번호를 이용한 과거 홀짝 분포·번호 합계 평균 및 공식 출처를 표기. 회차별 페이지에는 이전 회차 비교·번호 출현 횟수·인접 회차 이동을 추가하되 미래 당첨을 예측한다는 표현은 사용하지 않음.
- 로또 기록 허브에 **실제 저장된 100개 회차만 선택할 수 있는 바로 이동 기능**을 추가하고, PC·모바일에서 1240회 상세 페이지로 이동하는 실제 Chromium 테스트를 통과함. 당첨지역 통계는 **100개 회차의 판매점 당첨 기록 1,542건**임을 명시. 동일 판매점의 복수 당첨을 중복 집계하므로 고유 판매점 수와 구분하고 지역별 단위도 '곳'에서 '건'으로 바로잡음. 원자료의 '전남광주' 묶음 표시는 임의로 한 지역에 합치지 않고 별도 통합 분류임을 설명.
- 블록게임 하단 설명의 잘못된 '가로나 세로 줄' 안내를 실제 게임 방식인 가로 줄 삭제 규칙으로 수정. 자동 생성 원본을 수정해 이후 갱신에서도 유지.
- 문의 이메일을 문의·개인정보처리방침에 연결. 공통 푸터를 작은 회색 글씨로 정리하고, 기존 안내 링크가 있던 페이지는 중복 제거. 141개 방문자 HTML 검사와 자동 갱신 재적용/멱등성 테스트 통과.
- 저장된 최근 100개 로또 추첨번호·보너스·날짜·제목과 생성 HTML 및 최신 당첨금 자동 대조에서 불일치·누락 0건. **공식 원자료의 독립 진위 확인 또는 전체 판매점 정보 검증을 의미하지 않음.**
- 실제 운영 도메인 주요 14개 URL의 HTTP 응답·주요 문구 점검. 2026-09-18 실제 Chromium PC·모바일 **12/12 시나리오 통과**: 홈페이지, 퍼센트 계산, 증시 목록, 로또 회차 선택 및 상세 이동, 주요 서비스 제목 표시. 모든 기능을 완전 검증했다는 뜻은 아님.

## Search Console 실조회 (2026-09-18)

- 운영자가 `/stock/guide/` 및 `/lotto/history/`에 색인 생성을 요청함. 당일 URL 검사에서 두 페이지 모두 모바일 크롤러의 가져오기 성공·robots.txt 허용이지만 **'수집됨, 현재 색인되지 않음'**. 마지막 크롤링은 각각 2026-09-18 18:29 및 18:31 KST. 색인 요청이 실제 색인 완료를 의미하지 않음.
- 로또 회차 페이지 **표본 5개** URL 검사: 1241회·1240회는 '발견됨, 현재 색인되지 않음', 1200회·1180회·1142회는 Google이 아직 URL을 모름. 표본에서 전체 100개의 상태를 추정하지 않음. 대비 표본으로 스캐너 홈과 퍼센트 계산기는 색인 확인.
- 사이트맵에 제출된 137개 URL, 경고·오류 0건. 사이트맵 화면의 indexed=0은 별도 URL 검사에서 확인된 색인 상태와 다르므로 이를 전체 색인 URL 수로 사용하지 않음.
- 검색 실적의 **2026-08-19~09-15 정산된 28일 데이터**는 전체 17클릭·216노출. 사이트맵 URL 중 24개에 노출 기록이 있다는 뜻이지 24개가 색인됐다는 공식 집계가 아님. 로또 회차 상세 100개 중 같은 기간 노출 기록이 확인된 것은 1209회 한 개(11회 노출)이며, 나머지 회차들의 실제 색인 여부는 별도 URL 검사 없이는 알 수 없음. 검색 실적과 애드센스의 콘텐츠 가치 평가는 별개임.
- 라이브 페이지 검사는 기록 허브·스캐너 가이드·게임·회차 상세 HTTP 200 및 색인 허용·자기 자신을 가리키는 canonical을 확인. 이는 Google이 색인하거나 애드센스를 승인한다는 뜻이 아님.

## 운영자 판단 또는 접근이 필요한 지점

1. **애드센스 실제 거절 화면:** 두 차례 거절 사유 상세, 정책 센터에 별도 위반이 있는지, 사이트 및 ads.txt 상태를 운영자가 직접 확인해야 함. GitHub나 Search Console 연동으로 AdSense 내부 심사 상태를 조회할 수 없음. 화면을 확인하기 전 제3의 사유를 추측하지 않음.
2. **로또 100개 상세 페이지의 검색 노출 전략:** 기존 회차별 페이지를 모두 색인 대상으로 유지할지, 별도 기록 허브 중심으로 정리하고 일부/전체 회차를 `noindex`로 돌릴지 선택이 필요함. 후자는 검색에서 상세 URL의 발견 가능성을 낮추는 중요한 변경이며, 어느 쪽도 애드센스 승인 보장을 뜻하지 않음. 운영자 선택 전에는 100개 페이지를 삭제하거나 검색 제외하지 않음.
3. **검색 재처리:** 당일 새로 수집된 두 URL은 며칠 뒤 다시 검사. 같은 날 반복 요청하지 않음. 외부 뉴스/영상/공공데이터 사용 권한과 외부 원자료의 진위는 별도로 확인할 항목임.

위 항목이 아직 확인되지 않았다는 사실을 곧바로 오류나 승인 불가로 해석하지 않습니다. 애드센스 3차 신청 버튼은 누르지 않았으며, 운영자가 최종 화면을 확인한 뒤 직접 신청 여부를 정해야 합니다.
