# MODU.TODAY 애드센스 3차 신청 준비 점검 (2026-09-18)

이 문서는 실제 코드·배포 확인과 수동 확인이 필요한 사항을 구분한 작업 기록입니다. Google의 애드센스 검토 결과나 승인 가능성을 예측하지 않습니다.

## 확인된 수정과 검사

- 사이트 소유권은 애드센스 상세 화면에서 확인되었으나 콘텐츠 품질은 두 차례 거절되었음. 따라서 소유권·ads.txt만 해결하면 승인된다고 보지 않음.
- 뉴스 카드가 별도 CSS 없이도 읽히도록 수정하고, 외부 언론기사 링크임을 명확히 표시함. 자동 뉴스 생성 뒤 동일 수정이 유지되도록 후처리 추가.
- KRX 실제 데이터의 기준 거래일·종목 상승/하락/보합 분포·거래량 비교 예를 자체 계산해 홈페이지에 표시. 계산식/한계를 별도 스캐너 설명 페이지에 제공. 한국 시간대의 거래일 기준으로 검증함.
- 홈페이지의 사이트 이름만 있는 제목을 실제 서비스 범위를 설명하는 제목으로 수정하고, 설명문에 데이터의 성격 및 외부 언론 기사 링크임을 명시. 뉴스 자동 갱신/SEO 재생성 양쪽에 후처리 연결, 회귀 테스트 및 실제 사이트 반영 확인.
- 계산기 21종 허브에 수치 예제·기준값/상환방식 한계 설명 추가. 존재하지 않는 내부 메뉴 링크는 삭제하거나 실제 페이지로 교체함.
- 로또 100회 기록 허브에 원본 당첨번호로 계산한 과거 홀짝 분포·번호 합계 평균, 출처와 예측 불가 안내를 추가. 각 회차에는 과거 100회 범위의 번호 빈도·이전 회차와의 비교·앞뒤 이동 링크를 보강함. 회차별 기록을 일괄 삭제하거나 검색 색인 제외 처리하지 않음.
- 문의 이메일을 사이트 문의·개인정보처리방침에 연결하고, 공통 푸터 링크를 작은 회색 글씨로 정리. 소개·문의·개인정보처리방침·이용안내 링크 중복이 없도록 전체 방문자 HTML 141개 점검, 자동 갱신 후 재적용 및 멱등성 테스트 통과.
- 사이트 소유권 인증용 HTML을 제외한 방문자용 HTML 141개를 정적 검사. 검사기 정의의 구조적 항목은 0건이며, 그중 102개 로또 관련 기록은 별도의 편집상 표본 검토가 필요함. 내부 숫자/문단 길이는 Google의 공식 승인 기준이 아님.
- 로또 최근 100개 회차의 저장된 추첨번호·보너스·날짜·제목과 생성 HTML, 최신 1등 당첨금 데이터를 자동 대조: 불일치·누락 0건. **공식 외부 원자료 진위 또는 전체 판매점 내용의 검증을 의미하지 않음.**
- 실제 운영 도메인의 홈페이지·ads.txt·스캐너·방법론·계산기·로또 기록·YouTube·아파트·게임·소개·문의·개인정보처리방침·이용안내·sitemap 등 14개 URL의 HTTP 200과 주요 문구를 확인함.
- 실제 Chromium에서 데스크톱/모바일 총 12개 시나리오를 실행: 모두 통과. 홈페이지 뉴스 카드 색상, 퍼센트 계산 2건, 증시 종목의 동적 표시, 나머지 주요 페이지의 본문/제목 렌더링을 확인함.

## Search Console 실조회 (2026-09-18)

- 운영자가 `/stock/guide/` 및 `/lotto/history/`에 색인 생성을 요청함. 당일 URL 검사에서 두 페이지 모두 **Google 모바일 크롤러의 가져오기 성공·robots.txt 허용**, 그러나 **수집됨, 현재 색인되지 않음** 상태. 마지막 크롤링은 각각 2026-09-18 18:29 및 18:31 KST. 색인 생성 요청 자체가 색인 완료를 의미하지 않음.
- 로또 회차 페이지 **표본 5개만** URL 검사: 1241회·1240회는 '발견됨, 현재 색인되지 않음', 1200회·1180회·1142회는 'URL is unknown to Google'. 나머지 회차의 상태를 표본에서 추정하지 않음. 대비 표본으로 `/stock/`과 `/calculator/percent.html`은 각각 'Submitted and indexed'.
- `/sitemap.xml`은 제출된 137개 URL을 포함하고 오류 0건·경고 0건으로 조회됨. 사이트맵 집계의 indexed=0은 실제 URL 검사에서 색인 확인된 페이지와 일치하지 않아, 전체 색인 수를 0으로 단정하지 않음.
- GSC Wizard 라이브 페이지 검사에서 홈페이지·로또 기록 허브·스캐너 설명 페이지는 HTTP 200, 색인 허용, 각 페이지의 자기 자신을 가리키는 canonical 확인. 이는 검색 결과 노출이나 애드센스 승인을 보장하지 않음.

## 운영자 또는 연결 계정으로 추가 확인할 항목

1. 구글이 당일 수집한 새 페이지의 본문을 향후 색인하는지 추후 URL 검사로 확인. 반복적인 색인 요청이 처리를 앞당기지 않으므로 같은 날 재요청하지 않음.
2. 자동 생성된 로또 회차의 몇 개를 원자료 및 실제 방문자 관점에서 표본 검토. 외부 뉴스·영상·공공 데이터 사용 권한, 오래된 게시물의 정확성도 확인. 전체 사이트 정책 준수 여부는 정적 검사로 판단할 수 없음.
3. 애드센스의 정책 위반 세부 화면과 ads.txt 상태를 다시 확인한 뒤 운영자가 검토를 요청. 애드센스 내부 상태는 GitHub나 Search Console에서 확인하거나 대리 변경할 수 없음.

위 항목은 '검증 전'이지 '실패'를 뜻하지 않습니다. 검색 색인 상태와 Google 내부 심사를 확인하기 전에는 '승인 보장' 또는 '정책 위반 완전 해소'라고 말하지 않습니다. 신청 버튼은 사이트 운영자가 최종 점검 뒤 직접 눌러야 합니다.
