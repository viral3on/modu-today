제보할 때 도움이 되는 정보

  • 문제가 발생한 페이지 주소와 기능 이름
  • 재현 순서와 기대한 결과, 실제 표시된 결과
  • 공개 데이터 오류라면 기준일·회차와 공식 출처 URL
  • 개인정보가 보이지 않도록 가린 화면 캡처

개인정보 주의: 공개 GitHub 게시판에 이름, 연락처, 계좌, 급여, 주소, 로그인 정보 또는 개인별 계산 내역을 게시하지 마세요. 이메일 문의에서도 문제 해결에 필요하지 않은 민감한 정보는 보내지 않는 것이 좋습니다.
